StudyMate AI 📚

StudyMate AI is a web-based study assistant built with Python and Django. It helps students study more efficiently by extracting text from PDF documents, generating concise summaries, and creating quizzes for revision.

✨ Features

- 📄 PDF Upload: Upload study materials in PDF format.
- 📝 Text Extraction: Extract readable text from PDF documents using PyMuPDF.
- 🧠 AI-Style Summarization: Generate concise summaries using a free, extractive text summarization approach.
- ❓ Quiz Generation: Generate quiz questions from extracted study material.
- 🌐 Web Interface: Use the application through a Django-powered website.

🛠️ Technologies Used

- Python
- Django
- HTML and CSS
- PyMuPDF
- Git and GitHub

⚙️ Getting Started

Prerequisites

- Python installed on your computer
- Git installed
- Visual Studio Code or another code editor

Installation

1. Clone this repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder:
   
   cd StudyMateAI

3. Create a virtual environment:
   
   python -m venv venv

4. Activate the virtual environment on Windows:
   
   .\venv\Scripts\Activate.ps1

5. Install the required packages:
   
   pip install django pymupdf

6. Start the development server:
   
   python manage.py runserver

7. Open the local address shown in the terminal in your browser, usually:
   
   "http://127.0.0.1:8000/"
